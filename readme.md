# Student-Hub
A clean and modular web application designed to help students manage assignments and notes efficiently.

## Live Demo
https://student-hub-iota.vercel.app/

## Features
> Add, delete, and track assignments with due dates
> Create and manage personal notes
> Persistent data using browser localStorage
> Dark / Light theme toggle
> Modular JavaScript architectur

## Tech Stack

> HTML5
> CSS3 (custom styling, responsive layout)
> JavaScript (ES6 modules)
> LocalStorage API


## Project Structure

student-hub/
    - index.html
    - style.css
    - app.js
    - components/
        - tasks.js
        - notes.js
    - data/
        - storage.js


## How to Run Locally

### Using Node.js:
1. Run this in the folder:
```
npx serve
```

2. Then open the address in "Local" like:

```
http://localhost:3000
```

---

### Using Python:
1. Run this in folder:
```
python -m http.server 8000
```

2. Then open the address like:

```
http://localhost:8000
```
